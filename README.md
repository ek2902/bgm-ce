# The World's Bestest Internship

## About

This program runs the Blocky game, a Tetris-alike with functionality pulled from Tetris the Grandmaster. We completed the ARCHITECTURE.md file detailing the structure of the codebase, built a comprehensive test suite for the Well class, fixed several bugs, and added random block generation to the game, all while smiling, giggling, and kicking our feet with joy.

We fixed the issue of the game freezing when a piece was moved off the right end of the board, a piece not moving to the right if the shift right key was held, and added a delay between a block being placed and a new block spawning (with an increased delay if placing that block had caused any number of lines to be cleared).

We would not recommend this internship to future CSC-207 students, since our boss (AM Osera) looks suspiciously like and is about as punctual as our CSC-207 professor. Also, the codebase sucks.
